ANIRBAN PAL — ACADEMIC WEBSITE

Public website: https://alphago1234.github.io/
Repository: https://github.com/alphago1234/alphago1234.github.io

An independent static academic website. No package installation, framework,
database, tracking service, or JavaScript is needed to read the content.
JavaScript adds publication filtering and search as progressive enhancement.

EDITING
Edit data/profile.json for approved biography and public contact links.
Edit data/publications.json for publication records and exact status labels.
Edit build.py for page prose or layout; edit assets/style.css for styling.
Run: python3 build.py
Run: python3 validate.py
Commit generated HTML along with the data and generator.

HOSTING
GitHub Pages publishes the root of the main branch. .nojekyll prevents Jekyll
processing. Keep the personal-site repository separate from research code.
